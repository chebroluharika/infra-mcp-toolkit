RAG (Retrieval Augmented Generation) Flow

1
User Query
"Find tests related to login failure"
2
Generate Embedding
Convert query to vector using TEI (Text Embeddings Inference) via NSAgent
3
Vector Similarity Search
Search FAISS indexes (TestRail, GitHub repos, Documentation)
4
Retrieve Context
Top-K relevant chunks: test cases, code files, docs
5
LLM Processing
Llama 3.2 / GPT-4 generates answer with retrieved context
6
Response to User
"Found 3 relevant tests for login failure..."
